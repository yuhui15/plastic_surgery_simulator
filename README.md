# FaceForm 面部形态模拟器

FaceForm 是一个基于浏览器运行的面部形态模拟工具。用户上传一张正脸或侧脸照片后，依次标记六个面部关键点，再通过面部长宽比和瞳距面宽比调整，预览面部形态变化。

> 本项目仅用于视觉模拟、设计沟通和交互原型验证，不构成医疗建议，也不能预测真实手术结果。

## 功能

- 上传 JPG、PNG 或 WEBP 图片
- 支持拖放上传
- 图片仅在浏览器本地处理，不上传服务器
- 依次标记六个面部点：
  1. 发际线
  2. 下巴端点
  3. 左颧骨
  4. 右颧骨
  5. 左瞳仁
  6. 右瞳仁
- 使用真实的面部长宽比数值调整面部形态
- 使用瞳距面宽比数值调整左右瞳仁间距
- 可切换标记点的显示和隐藏
- 支持撤销、重置和清除标记点
- 导出 PNG 预览图
- 支持桌面端和移动端布局

停止服务器时，在 PowerShell 中按 `Ctrl + C`。

## 使用步骤

1. 上传一张清晰的人脸照片。
2. 按顺序点击六个面部点：
   - 发际线
   - 下巴端点
   - 左颧骨
   - 右颧骨
   - 左瞳仁
   - 右瞳仁
3. 六个点完成后，两个比例控件会启用。
4. 调整面部长宽比或瞳距面宽比观察对应变化。
5. 点击“导出预览”保存 PNG 图片。

## 长宽比定义

界面中的长宽比定义为：

```text
面部高度 ÷ 面部宽度
```

其中面部高度和宽度来自前四个标记点形成的包围区域。

- 数值变大：面部横向压缩，视觉上更窄、更长
- 数值变小：面部横向拉伸，视觉上更宽
- 保持原始数值：维持上传图片中的原始比例
- 左右瞳仁及周边保护区不会随面部长宽比拉伸或压缩

### 瞳距面宽比

瞳距面宽比定义为：

```text
左右瞳仁中心距离 ÷ 面部宽度
```

调整瞳距面宽比时，只移动左右瞳仁区域及其标记点，发际线、下巴端点和左右颧骨保持不动。调整面部长宽比时则相反，瞳仁区域和瞳仁点保持不动。两个指标按公式联动：

```text
当前面宽 = 面部标记高度 ÷ 当前面部长宽比
当前瞳距面宽比 = 当前瞳距 ÷ 当前面宽
调整瞳距面宽比时的目标瞳距 = 目标瞳距面宽比 × 当前面宽
```

所以改变面部长宽比时瞳距像素距离保持不变，瞳距面宽比会根据新面宽即时重算；调整瞳距面宽比时，则使用当前面宽计算目标瞳距。

## 技术实现

项目使用原生 HTML、CSS 和 JavaScript 实现，不依赖前端框架或第三方运行时。

核心处理流程：

1. 使用 Canvas 读取上传图片的像素数据。
2. 保存原始图片像素和六个标记点的位置。
3. 每次调整比例时，都从原始图片重新计算，不基于上一次变形结果叠加。
4. 使用反向采样和双线性插值生成像素。
5. 在面部区域边缘使用平滑衰减，让变形更接近美颜软件中的液化/推脸效果。
6. 根据当前指标只更新对应的标记点：面部长宽比更新前四点，瞳距面宽比更新左右瞳仁点。
7. 面部长宽比的逆向采样在瞳仁保护区内使用零位移，并在周边平滑衰减；瞳距调整使用独立的局部平移场。

这种方式可以减少重复变形导致的重影和累计失真。不过，当前版本仍是基于六点区域的二维视觉模拟，不包含人脸识别、三维建模或真实医学模拟。
