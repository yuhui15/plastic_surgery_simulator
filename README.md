# FaceForm 面部形态模拟器

FaceForm 是一个基于浏览器运行的面部形态模拟工具。用户上传一张正脸或侧脸照片后，依次标记四个面部关键点，再通过真实的面部长宽比调整，预览面部横向压缩或拉伸后的视觉效果。

> 本项目仅用于视觉模拟、设计沟通和交互原型验证，不构成医疗建议，也不能预测真实手术结果。

## 功能

- 上传 JPG、PNG 或 WEBP 图片
- 支持拖放上传
- 图片仅在浏览器本地处理，不上传服务器
- 依次标记四个面部点：
  1. 发际线
  2. 下巴端点
  3. 左颧骨
  4. 右颧骨
- 使用单一的真实长宽比数值调整面部形态
- 支持撤销、重置和清除标记点
- 导出 PNG 预览图
- 支持桌面端和移动端布局

## 运行方式

项目不需要安装依赖，使用 Python 启动静态文件服务器即可。

### Windows PowerShell

```powershell
cd path\to\plastic_surgery_simulator
python -m http.server 4173
```

如果系统中 `python` 命令不可用，可以使用：

```powershell
py -m http.server 4173
```

然后在浏览器打开：

```text
http://127.0.0.1:4173
```

停止服务器时，在 PowerShell 中按 `Ctrl + C`。

## 使用步骤

1. 上传一张清晰的人脸照片。
2. 按顺序点击四个面部点：
   - 发际线
   - 下巴端点
   - 左颧骨
   - 右颧骨
3. 四个点完成后，长宽比控件会启用。
4. 调整长宽比数值观察面部变化。
5. 点击“导出预览”保存 PNG 图片。

## 长宽比定义

界面中的长宽比定义为：

```text
面部高度 ÷ 面部宽度
```

其中面部高度和宽度来自四个标记点形成的包围区域。

- 数值变大：面部横向压缩，视觉上更窄、更长
- 数值变小：面部横向拉伸，视觉上更宽
- 保持原始数值：维持上传图片中的原始比例

## 技术实现

项目使用原生 HTML、CSS 和 JavaScript 实现，不依赖前端框架或第三方运行时。

核心处理流程：

1. 使用 Canvas 读取上传图片的像素数据。
2. 保存原始图片像素和四个标记点的位置。
3. 每次调整比例时，都从原始图片重新计算，不基于上一次变形结果叠加。
4. 使用反向采样和双线性插值生成像素。
5. 在面部区域边缘使用平滑衰减，让变形更接近美颜软件中的液化/推脸效果。
6. 根据当前长宽比同步更新四个标记点的位置。

这种方式可以减少重复变形导致的重影和累计失真。不过，当前版本仍是基于四点区域的二维视觉模拟，不包含人脸识别、三维建模或真实医学模拟。

## 浏览器要求

建议使用最新版的：

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

浏览器需要支持 Canvas、File API、ImageData 和 Pointer Events。
